# v0.2「共振」 / Resonance

2026-09-09。本轮围绕可组合攻击、圣所美术与分层声音升级；保留八区域行动、五种普通敌人和两种 Boss。

## 攻击可以怎样组合

协议从 30 项增加到 40 项，五系各八项。形态、弹道、命中载荷由同一组派生属性共同作用，780 对卡牌在不同获取顺序下得到相同结果。

| 新协议 | 行为与取舍 |
| --- | --- |
| 赤核陨星 | 弹体更大、更慢、更重，降低射击频率 |
| 星火胚芽 | 首次命中生成三枚弱次生弹，继承部分载荷，不能递归分裂 |
| 贯星光矛 | 高速、长尾、贯穿，提高射击间隔；使用弹体扫掠碰撞 |
| 浮游使魔 | 身旁浮游体定时向敌人发射次生弹 |
| 蜿蜒频谱 | 波动弹道，可与追踪、反弹和环绕叠加 |
| 碎星扇面 | 增加两发弹体，降低单发伤害 |
| 微型星系 | 先绕玩家旋转扩张，再离轨飞行；撞墙反弹会提前离轨 |
| 逆因果回旋 | 短暂出射后返航，无可用反弹时在边界提前返航；不会重复命中同一敌人 |
| 镜像裂雨 | Dash 产生八枚全向次生弹 |
| 双向因果 | 每次主射击额外向后发射一枚弱次生弹 |

## 六种跨系反应

| 反应 | 条件 | 效果 |
| --- | --- | --- |
| 电浆回路 | 余烬协议 + 电弧引擎 | 电弧命中燃烧目标时消耗部分燃烧，产生小范围电浆爆发 |
| 超导棱晶 | 冰霜编码 + 电弧引擎 | 电弧优先寒冷目标，可额外连接一次 |
| 热裂变 | 余烬协议 + 冰霜编码 | 再次命中已携带燃烧和寒冷的敌人，引发热冲击；目标冷却 1.2 秒 |
| 星轨棱镜 | 棱镜反射 + 引力偏移 | 反弹后加强追踪，首次反弹延寿，每次反弹损失部分伤害 |
| 坍缩火种 | 熔火弹头 + 事件视界 | 奇点内的溅射集中到奇点中心，范围与伤害增强 |
| 瞬电残响 | 越界射击 + 电弧引擎 | Dash 后短窗口内的前三次射击，在起点额外产生电针 |

具体 ID、名称和卡牌数值以 `src/cards/catalog.ts` / `synergies.ts` 为准。奖励、档案和 HUD 使用同一份反应条件；已有元素共鸣继续生效。次生弹不再次触发完整命中链，每步反应预算和每目标冷却限制连锁规模。

## 立即体验

主菜单 → **协议试炼**。六套配置分别展示三相炼星、折光星群、电浆圣歌、冰环天体、裂隙光矛、相位织雨。试炼无敌、无限波，不覆盖正常行动的检查点、发现记录和统计；退出后可继续旧行动。

建议先试「冰环天体」观察星轨，再试「相位织雨」持续射击并 Dash，最后用「裂隙光矛」按 E 聚怪比较坍缩效果。

## 美术与声音

两张原创生成图片用于裂隙菜单与俯视圣所地面，暗石、铜金与青色符文形成统一环境。四种房间使用不同色调，角色与敌人仍以代码几何绘制。陨星、光矛、冰晶、环绕使魔、反弹与双元素配色有对应表现。图片生成提示及许可说明见 [美术记录](art-direction-v02.md) 与 [素材清单](../assets/LICENSES.md)。

音乐为原创 112 BPM、四小节循环乐谱，由 Web Audio 合成和弦、低音、琶音与打击层，随战斗及 Boss 阶段调整密度；五系射击使用不同音色。总声部上限 30，音乐上限 12；音乐、音效、总音量分别控制，暂停立即停止音乐调度。

## 本轮修复与范围

- 嵌套电浆爆发导致同一敌人重复结算击杀、经验与回血。
- 环绕弹贴墙重复消耗反弹、反射方向错误，以及分裂弹寿命与回旋门槛不同步。
- 回旋弹在实际竞技场中先撞墙消失；加入提前返航，并验证中央及近墙四向回收。
- AudioContext 重建后的限流时间、噪声声部上限、静音与失焦暂停。
- 试炼的无限波数显示和顶部信息重叠。

v0.1 的存档格式与旧卡 ID 保留，无需玩家清空存档。本轮未增加第三个 Boss、迷宫碰撞布局、精灵动画集、手柄或触屏战斗。自动验收与性能样本见 [QA](qa-report.md) / [性能](performance.md)；流派平衡与长期音频听感仍需真实玩家反馈。

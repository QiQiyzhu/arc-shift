# ARC//SHIFT · 展示说明草案

中文作品说明：魔法文明和失控网络交汇之后，行动者穿越十二层异常区域。圣剑、法器与重炮可以熔接；元素、弹道和命中反应共享，让同一组协议在近战剑弧、符文剑气和重炮弹片上呈现不同战术。跃迁、清弹脉冲和引力场为高风险构筑提供操作空间。

English description: ARC//SHIFT is a browser action roguelite set in an arcane civilization entangled with a broken machine network. Fuse a sword, an arcane focus, and a heavy cannon. Shared trajectory and elemental protocols transform melee arcs, rune blades, and explosive shells into a single build. A dash, a bullet-clearing pulse, and a gravity well turn positioning into part of the build. The guided practice mode introduces the controls, offers two fusion paths, and leads into a boss encounter without affecting campaign progress.

创新陈述：本项目的展示重点是「同一协议如何通过三种攻击载体产生不同操作策略」，而不是声称发明了构筑肉鸽或元素反应。演练可迅速体验组合；正式十二层路线通过资源和遭遇逐步获得武装。相似类型与原创边界见 competitive-analysis.md。

建议现场演示：打开主菜单「第一次跃迁」，完成或跳过基础提示 → 二选一熔接 → 近身挥砍看第三斩剑气与副武装轮替 → 打守门人 → 回主菜单开始正式行动，展示选卡前后数值、路线与资源选择。演练无敌；必须明确这一点。时长依实际操作，不预填完成时间。

键鼠：WASD 移动；鼠标瞄准；左键持续攻击；Space 跃迁；Q 脉冲清弹；E 引力场；B 炸弹；R 灵药；Esc 暂停。可改键，界面跟随当前绑定。标准手柄战斗已实现，实体手柄未验证；菜单仍以键鼠为主。移动端可浏览，不宣称支持触屏战斗。

Controls: WASD to move, mouse to aim, hold LMB to attack, Space to dash, Q for pulse, E for gravity well, B for bomb, R for potion, Esc to pause. Rebinding is available. The current player-facing interface is primarily Chinese; this description is not a claim that the entire game has English localization.

# ARC-SHIFT v2.0 验证与原始证据

日期：2026-09-18。产品版本2.0.0；主线模拟1.2-protocol.1；星铸试炼规则2.0-contract.2。测试时源码在基线提交06203d83a4a6dbfccbdb5398d064c91d8c8fb2a8之后修改，性能文件的baseCommit只表示当时HEAD；以各文件内源码SHA256识别被测快照，不能将baseCommit误当最终版本。

## 功能与行为

- `unit-results.json`：238通过、0失败；包括旧回放、配置、存档、碰撞、合约重复操作、生命门槛、配置v1迁移、特殊终结击、冲锋轨迹与六类落点对照。
- `browser-core-results.json`：7项通过；`browser-final-results.json`：3项通过。v2边界用例重复执行一次，共9个不同测试场景，并非10个不同场景。直接设置生命的边界夹具与只读实机录制区分。
- `production.json`：生产构建6项检查，包含入口、画布、Escape暂停、退出保护，以及QA全局/开发编辑器不暴露；未宣称全站所有路径穷举。
- `behavior-final.json`与`behavior-baseline.json`：逐120步验证三武器、空间网格与暴力扫描路径；1200固定步内的checksum、事件、击杀和掉落与旧记录逐项一致。
- `recorded-run.json`：视频实际导出，法器夺能三关通关，生命120→合约支付20→最终100。没有通过世界状态写入修改生命、伤害、击杀或时间。
- `actual-cannon.json`：重炮夺能通关，最终39生命；`actual-sword-failure.json`：剑补给第三场死亡（造成3937/4200伤害）。额外法器失败样本也保留。它们是不同输入运行，不能当武器公平排名。

## 数值实验

`experiment.json`包含完整配置、三武器×两合约×三种子共18局，10完成、8失败，38202战斗步、43620含过场输入步。脚本有敌弹与边界规避，没有专门处理冲锋/地面落点。每武器两条路线同配装，不维修；末关8点配装未使用额外额度。该实验验证既定策略的结果，不能证明额外额度没用、武器强弱或真人通过率。

`options.json`另按四槽、价格和前置枚举：末关9点172种、11点191种。组合数量不替代真人对有用性、乐趣和难度的判断。

证据ZIP另保留`pilot-before-cost/`。它使用旧12+2预算、不同末关配装且没有20生命支付，与最终版本不是严格A/B。

## 性能

同一i9-13900HX设备、Edge153.0.4234.32、1440×900、DPR1、种子73129、完整特效与相同输入，每场景3轮。每样本严格120热身+600测量世界步，worldTicks720、poolMisses0；最终checksum、RNG、伤害、事件序列、钱包及敌人数一致。下表是各指标三轮中位数。

| 敌人数/地形 | 整帧P50前→后ms | P95前→后ms | P99前→后ms | >33.3ms前→后 | 同步绘制P95前→后ms |
|---|---|---|---|---|---|
| 28 / 无 | 6.9→6.9 | 12.1→13.4 | 19.6→18.9 | 0→0% | 4.6→4.2 |
| 100 / 有 | 8.2→8.6 | 19.4→19.4 | 23.4→23.5 | 0.09→0% | 9.3→8.5 |
| 250 / 无 | 16.0→16.9 | 30.3→30.7 | 35.6→35.9 | 2.61→2.01% | 18.6→15.8 |

v2中间版本250敌P95曾升到33.1ms、绘制20.6ms；CPU采样定位Phaser轮廓线细分后，缓存顶点与三角条带令绘制降到15.8ms，整帧回到30.7ms。同步提交更低，不等于所有整帧指标改善；画面准备P95从3.3升到4.9ms，模拟P95从1.8到2.1ms，HUD/音频回调0.2到0.3ms。没有靠减少模拟工作量取得结果。

两个独立250敌trace用于归因，不混入上表：修正前后标记区间GC事件341→296，总耗时951.341→1146.659ms、最长10.8→16.56ms，**未见GC耗时改善**。分配采样与CPU采样覆盖初始化/热身，GC摘要仅针对测量标记区间。

局限：前后顺序批次，非随机交错；首个基线样本短暂与独立截图浏览器重叠；系统后台活动不完全可控。DEV无头、局部同步CPU计时，不代表GPU执行时间、React完整提交或玩家生产FPS。高生命压力夹具不能验证掉落，另以可击杀行为对照补足。

## 附件与复现

`output/ARC-SHIFT_v2.0_设计与原始证据.zip`包括三批吞吐原始results、两个CPU/GC/分配trace、实验成功和失败记录、素材提示回执、视频截图与可编辑文档。MP4和PDF单独提供，便于直接作为招聘附件。

在完整项目安装依赖后：

```text
npm test -- --reporter=json --outputFile=outputs/v2/unit-results.json
npm run test:e2e -- e2e/game.spec.ts e2e/combat-feel.spec.ts e2e/trial.spec.ts e2e/v2.spec.ts
node scripts/v2-experiment.cjs
node scripts/v2-options.cjs
node scripts/client-behavior.cjs . v2-behavior
node scripts/client-performance.mjs new-label
node scripts/client-performance.mjs new-profile --trace
node scripts/record-v2.mjs outputs/new-record --record --weapon=arc
```

浏览器脚本要求本机Edge及5173开发服务；生产检查要求先build并在4173启动preview。复现前后对照需各自的源码快照，不能用同一份最终源码假装旧版本。原始测量文件的哈希可核验快照。

视频为真实引擎、脚本键鼠操作，非真人测试。录屏器在静态合约页保留了上一帧，成片该区间插入同次运行的`08-contract.png`实机截图，字幕明确标识；没有替换战斗结果或补画游戏行为。视频无配音，保留合成游戏音效与讲解字幕。视频录于最后一次纯绘制三角条带优化前，战斗和合约规则相同；最终生产包另有构建检查。

本地单机，不宣称在线可信运营；退出试炼不保留该局。真人首次体验、理解成本与乐趣评价仍需用户参与。

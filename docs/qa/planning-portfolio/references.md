# ARC//SHIFT 系统与数值策划参考来源

核实日期：2026-09-18。以下均为奖项主办方或游戏开发者／发行商的一手页面。奖项事实与ARC设计转译应分别表述；这些作品获奖并不证明ARC已经达到同等质量。奖项年份不是游戏发售年份。

1. **Balatro — 2025 GDCA Best Design获奖**；同时获Game of the Year、Best Debut及Innovation Award。正式游戏于2024年2月推出，不应写成“2025获奖Demo”。[GDC官方获奖公告](https://gdconf.com/article/-balatro-plays-winning-hand-at-gdca-2025-receiving-game-of-the-year/)。[游戏官方FAQ](https://www.playbalatro.com/faq)介绍有限Joker槽位、商店与具有特殊限制的Boss Blind。ARC转译：通过有限预算产生输出、容错与后续收益之间的取舍，不复制扑克或Joker设计。

2. **Blue Prince — 2026 BAFTA Game Design获奖**；Best Game为提名，不能改写成最佳游戏获奖。它是正式游戏，2025年4月推出。[BAFTA官方获奖公告](https://www.bafta.org/media-centre/press-releases/winners-2026-games-awards/)。[发行商Raw Fury机制介绍](https://rawfury.com/games/blue-prince/)说明选房影响探索路径，房间与工具共同决定当日进展，宅邸每日重置但部分升级保留。ARC转译：让下一场敌人信息和剩余资源影响当前构筑选择，不移植房间谜题或重置结构。

3. **Tactical Breach Wizards — 2025 IGF Excellence in Design获奖**；2025 BAFTA Game Design仅提名。正式版于2024-08-22发售，当前另有Demo。[IGF官方2025获奖记录](https://igf.com/finalists-and-winners?id=39)。[开发者Steam页面](https://store.steampowered.com/app/1043810/Tactical_Breach_Wizards/)介绍技能组合与免费回溯，也记载复杂早期Demo难以让新玩家理解、最终被更简单版本替换。ARC转译：提供固定条件的短试炼，让选卡后果可以比较；保持实时战斗身份。

4. **Furniture Fu — 2025 BAFTA Young Game Designers，Game Making Award，15–18岁组获奖**。这是青年制作类别，不是IGF Best Student Game；获奖时属于可玩原型类别，之后正式版于2026-08-19发售，当前也提供Demo。[BAFTA官方获奖公告](https://www.bafta.org/media-centre/press-releases/winners-15th-young-game-designers/)。[作者Steam页面](https://store.steampowered.com/app/3645490/Furniture_Fu/)说明家具布置与战斗能力、组合协同的联系。ARC转译：让协议的触发条件、参数变化和后续反应具有一致规则，不复制家具题材或内容规模。

PDF短引用可写为：Balatro（GDCA 2025最佳设计）、Blue Prince（BAFTA 2026游戏设计）、Tactical Breach Wizards（IGF 2025卓越设计）、Furniture Fu（BAFTA YGD 2025制作奖15–18岁组）。机制分析和ARC应用方案均为本项目设计推导，不能写成评委公布的获奖原因。

补充专业材料：[Steve Lee，GDC 2025《The Unusual Level Design of Tactical Breach Wizards》](https://gdcvault.com/play/1035595/Level-Design-Summit-The-Unusual)，由该游戏关卡设计师讲述其设计流程。它是开发者演讲，不是另一项游戏奖。

# v1.0「钟声尽头」

2026-09-10。新行动采用十二层、二十八节点的路线图；v0.3 未完成的八区域行动保留原有路线和经营规则。

## 武装不再互斥

营地选择一件主武装。局内工坊与武库可熔接其他武装，按住左键时副武装自动攻击，共享本局元素、弹道与命中效果。第二层第一次熔接免费，后续工坊熔接为 18 金币；武库熔接免费。主武装保持自己的攻速，副武装有独立冷却与 55% 基础伤害系数。

| 组合 | 实际行为 |
| --- | --- |
| 圣剑 + 法器 | 圣剑第三斩额外发出五道扇形剑气 |
| 圣剑 + 重炮 | 剑弧首次命中附带一次范围爆破 |
| 重炮 + 法器 | 炮弹命中后额外散出四枚弹片 |
| 三件齐备 | 上述行为共同生效；可继续叠加元素、折射、回旋、环绕等协议 |

次生弹不递归裂变；一次挥砍只触发一次混搭爆破。慢速构筑的连段窗口随攻击间隔调整。试炼新增“三重共鸣”开关，可在六套原有元素组合上演示三武装共用协议。

## 可规划的行动

全图可查看未来节点的类型、收益和异变。只能前往下一层相连节点，选择后无法返回。第 4、8、12 层必须经过核心：守门人、挽歌圣母或灰烬执政官、零号神谕。一局三个 Boss，第二核心随种子变化；图鉴合计四种 Boss。

十种节点包括战斗、精英、守点、行商、篝火、工坊、档案、武库、遗迹、核心。守点需在中央范围累计驻守 18 秒，最多五波敌人，离开符阵暂停累计。档案提供协议和记忆；遗迹可用金币敲钟或生命偿债。篝火可以当场回血或带走灵药。武库的钥匙箱、行商的库存与中继站归档独立于主要遭遇选择，完成主要选择后仍可操作。

## 世界与成长

沉钟圣所、悼亡林地、余烬铸庭拥有独立地面。灰烬执政官的核心使用铸庭场景。竞技场存在封闭角落、实体障碍、周期陷阱和祝祷符阵；墙体阻挡移动、Dash、子弹与剑弧。祝祷加速 Q/E 冷却，地面符号和充能环显示陷阱时机。

新增余烬投弹手、失声唱诗者和折镜幽影，分别提供延迟爆破、同伴护盾、侧翼瞬移与扇形射击。四种 Boss 具有阶段变化、预警和恢复窗口。

六件遗器通过归档碎片解锁，其中四件同时要求击败对应 Boss。出发可装备一件，局内工坊可花 25 金币熔接已解锁遗器。十二篇原创记忆通过区域、Boss 和选择收集；物品描述保留叙事空白。

主界面保留开始、继续、营地与设置。行装养成、遗器、协议档案、异常图鉴、记忆、试炼和指南归入营地二级菜单。装备和解锁保存在当前浏览器，不跨设备同步。

## 声音与技术

三个区域和四个 Boss 分别采用原创四小节乐谱，78–132 BPM 基础速度。挽歌圣母保留林地旋律，阶段变化抬高音域；执政官加强节奏；神谕最后阶段降至 86 BPM 并稀疏打击乐。阶段音乐在小节边界切换，暂停停止编排，胜利以衰减和弦结束。没有使用参考游戏的音轨或音效采样。

新增路线和事件存档校验，校验完整路径、当前节点与阶段一致性；不合法的检查点不会删除局外档案。恢复入口不会叠加遗器入场护盾。开发场景与完整自动控制器分别验证后期画面和合法整局流程；生产包移除测试入口。

具体证据见 [验收记录](qa-report.md) 和 [性能记录](performance.md)。这是可在线展示的原创可玩项目；几何角色和合成配乐是本项目的表现路线，真人平衡仍需要更多反馈。

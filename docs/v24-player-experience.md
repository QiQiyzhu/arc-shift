# ARC-SHIFT v2.4 — 玩家入口与存档可靠性

验证日期：2026-10-07。版本定位为发布候选；保留 v2.3 的边境双路线、三武器、构筑远征、中继挑战和完整中英文内容。

## 本轮玩家可见变化

- 主界面直接显示行动目标、当前移动/攻击/闪避按键，并提供新手引导快捷入口。顶栏可直接切换中英文或打开操作指南。1366×768 英文首页可同时看到全部模式入口、营地和教练。
- 继续行动显示武器、检查点生命、累计时间及具体恢复位置。开始新行动时若存在检查点，必须先确认替换；完成演练后转入正式行动也经过同一保护。
- 暂停界面解释保存边界：区域入口与奖励自动保存，战斗内的血量、击杀和消耗品变化会在恢复检查点时重置；演练不覆盖主行动。
- 系统设置支持 JSON 备份下载、选择文件、预览、取消及确认恢复。恢复只在主界面开放。写入浏览器失败时不应用备份，不改当前运行时进度。
- 备份包含主行动检查点、营地进度及声音/语言设置；不包含独立模式记录或自定义按键。文件大小上限为 512 KiB。新的备份格式会拒绝错误版本、缺失/损坏字段、未知内容及任何会被旧存档解析器悄悄舍弃或重置的数据。原有本地旧存档迁移规则保持兼容。
- 各生产模式的懒加载入口具有加载界面、12 秒等待提示、错误恢复页和重新加载入口。重试不会清除浏览器存档。主行动场景加载过慢也有重试入口。
- 触屏访客会收到可关闭的外设说明；尚未提供触屏战斗按键。全屏请求被浏览器拒绝时显示可继续窗口游玩的提示。

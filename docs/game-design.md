# ARC//SHIFT · Game Design Mini Spec

## 产品与世界

一款桌面键鼠优先的原创 2D 俯视角动作肉鸽。古代魔法文明留下的奥术网络被自主 AI 接管；玩家作为 Arcanist，沿十二层分支地图规划行动，混搭武装并进入异常区域，用新协议改写自己的战斗方式，最终净化零号神谕。

视觉原则：深色矿石与电路地面、可辨认的几何敌人、青色玩家、红色危险预警、低饱和环境和高亮技能。主题色分别为火焰橙、雷电紫、冰霜青、虚空粉紫、跃迁黄绿。角色、美术、名称、地图装饰、声音与故事均为本项目创作。

## 初版开发顺序（历史）

1. 单房间：加减速、归一化移动、瞄准、射击、Dash、追击/射击/冲锋三种敌人。
2. 协议：从三种初始元素开始，清房三选一，形成五条可组合路线。
3. Run：八个区域，战斗/精英/修复/宝藏/核心，入口与奖励检查点。
4. Boss：第 4 区域守门人，第 8 区域零号神谕。
5. 打磨：声音、粒子、伤害飘字、完整 UI、浏览器回归与截图复查。

## 核心操作

| 操作 | 输入 | 基准 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 250 px/s；快速起步与制动；斜向归一化 |
| 瞄准与攻击 | 鼠标 / 按住左键 | 16 伤害，0.18 s 间隔，720 px/s 弹速 |
| 相位跃迁 | Space | 0.16 s 冲刺，1.2 s 冷却；无敌窗 0.22 s |
| 湮灭脉冲 | Q | 范围伤害、短减速、清弹；6 s 冷却 |
| 引力奇点 | E | 指向投放，牵引普通敌人并持续伤害；10 s 冷却 |
| 暂停 | Esc | 停止所有战斗模拟 |

120 初始生命；受击后有 0.7 s 无敌。Dash 不会缩短已有的更长无敌。敌人攻击不是追踪到命中瞬间：冲锋和范围预警会锁定目标位置。

## 敌人与 Boss

蚀刻者追击；棱镜哨兵保持射击距离；裂隙冲锋者锁定方向后突进；咒域编织者投放延迟爆破；修复中继回复附近同伴。v1.0 另有延迟爆破投弹手、护盾唱诗者与侧翼瞬移幽影。敌型通过轮廓、颜色与预警区分。

第七守门人依次进行扇射、冲锋、分布式爆破。零号神谕使用径向弹幕、双向旋转激光、爆破和召唤。v1.0 新增挽歌圣母的音浪、根网与召唤，以及灰烬执政官的十字熔断和重型冲锋。四种核心在生命低于 65% 和 30% 时切阶段；切换取消旧攻击并清空敌方弹幕。激光的预警与碰撞共用几何数据。

## 构筑与随机性

40 个不重复协议，5 系各 8 张。常见、稀有、史诗由边框、字色和光效区分。奖励优先寻找可补齐跨系反应的卡，再提供已有元素与探索选项；缺前置的卡不会提前出现。精英奖励至少提供一个非普通协议。同系 3 张启动共鸣。

- 火焰：燃烧、溅射、死亡爆炸、三重扇射、Dash 火迹；新增重型陨星与命中分裂。
- 雷电：电弧跳跃、暴击范围伤害、穿透、超频；新增高速贯穿光矛与浮游使魔。
- 冰霜：减速、脆化、碎裂、穿透、装甲、反弹；新增波动弹道与宽幅扇射。
- 虚空：追踪、奇点扩展、低血增伤、击杀回血、技能冷却；新增环绕与回旋。
- 跃迁：短冷却、护盾、近身爆发、冰环、闪避后射速、移速；新增 Dash 全向弹雨与反向射击。

形态、弹道与命中载荷同时派生，不采用“最后一张覆盖攻击”的规则。例如陨星 + 扇射 + 燃烧 + 寒冷生成三发携带冷热状态的重弹；反弹 + 追踪 + 分裂 + 波动保留各层行为。可见轮廓在同时持有陨星和光矛时优先使用陨星，但高速与贯穿数值仍保留。六种跨系反应的条件和效果见 [版本说明](v02-release.md)。

「协议试炼」提供六套预设组合，无敌、无限波、可切换与退出；不覆盖已有检查点，不增加发现记录和行动统计。它用于快速比较流派手感，正常行动仍需逐房获得协议。

v1.0 使用十二层、二十八节点的有向无环图，十种节点允许选择作战、经营和叙事遭遇；第 4、8、12 层经过核心。玩家可预览后续收益与风险，主动绕开部分战斗。三种地区拥有独立地面，封闭角落、实体障碍、周期陷阱与祝祷符阵改变站位。旧八区域路线仅用于继续旧存档。详细规则见 [v1.0 版本说明](v1-release.md)。

## 节奏与验收边界

新行动普通房 3 波、精英房 4 波，间隔 9 秒。守点最多 5 波，必须在中央累计驻守 18 秒；清空敌人不会跳过目标。非战斗遭遇可快速经过，强攻路线产生更多战斗与协议。计时见验收报告；真人还包含读卡、观察与决策，Bot 通过率不等于真人难度结论。

本版没有联网、云存档、商业音轨、触屏战斗、通用导航网格或战斗回放。敌人使用碰撞滑动与受阻侧移，幽影瞬移校验落点。后续适合先收集真人手感、难度与组合平衡反馈。

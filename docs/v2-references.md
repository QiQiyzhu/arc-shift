# ARC-SHIFT v2.0：获奖作品参考与五项设计转译

核实日期：2026-09-18。补充既有 Balatro、Blue Prince、Tactical Breach Wizards、Furniture Fu 研究。本轮只选三个有官方获奖记录、能补足战斗或美术方向的作品。下列奖项事实与 ARC-SHIFT 改造建议分别陈述；设计建议是本项目推导，不是主办方公布的获奖原因。

## 建议收敛成五项 v2 改动

1. **统一战斗美术的视觉层级。**借鉴 Hauntii 的风格一致性，为 ARC 保留自己的工业能量语言：背景压低对比，玩家使用稳定主色，敌方危险使用稳定警示色，奖励另用一种强调色；敌人轮廓随功能区分。地面预警、敌方弹体始终高于友方爆炸、拖尾与环境装饰。以同一段最密集战斗截图检查普通、灰阶与低动态效果三种显示，避免仅靠色相区分危险。投入先用于角色轮廓、敌人状态、地面与 VFX 的一致性。

2. **把现有武装做成三种动作选择。**参考 Hades II 的武装差异，将现有电弧／近战／重炮分别明确为持续中距压制、贴身承诺与恢复、低频爆发与区域控制；每种都要有可辨识的预备、命中、恢复，配套不同音色与轻重反馈。记录输入缓冲和取消窗口，避免换形态只改变粒子颜色或 DPS。验收时用无卡基础配置录制三段短战斗，应能从动作及站位分辨武装。

3. **让防守成功产生一个有限的进攻机会。**从 Nine Sols 提炼“判断时机—避开威胁—获得窗口”，优先打磨现有冲刺的起止反馈和 Boss 恢复时间。若新增奖励，仅考虑一次精确闪避后获得一次有上限的下一击强化；每次冲刺最多触发一次、有冷却，并由真实威胁判定，避免无敌期刷奖励。它不应新增按键或取代普通走位。先验证命中／擦身／无威胁三种情况及镜头、音效是否明确，再决定是否启用奖励。

4. **让有限预算改变打法，并展示选择代价。**延续 Balatro 的有限槽位与 Hades II 的战斗改造思路，精选现有协议做出单体、清群、控制／容错三类可辨识组合；卡面直接显示“当前→装备后”的行为变化、能量占用和冲突条件，下一房威胁作为选择上下文。延用 6 能量、4 槽进行可行组合统计；固定靶场 DPS 之外补充移动目标和分散目标，观察命中率、生存与资源效率。降费用只改变可装备组合，不能被写成同一配装的战斗收益。

5. **用短关卡链展示系统深度。**沿用现有敌人与 Boss，构建“单独认识威胁→两类威胁组合→Boss 检验”的房间顺序；每房围绕一个明确空间问题，房间间保留短暂选卡／修整节奏。Boss 保留少量标志动作，通过目标位置、追击顺序和恢复窗口产生变化；转阶段同时变化动作节奏、灯光与音色，避免仅靠提高血量与弹幕密度。验收记录首次受伤原因、选择变化和通关时间，展示玩家学到了什么。

实施优先级建议：1 和 2 先建立可读性与手感；4 和 5 让求职展示能解释系统设计；3 作为范围受控的试验，通过验证后再保留。以上指标是后续验收建议，不能写成已经完成的人类可用性测试或获奖级认证。

# ARC//SHIFT · 三分钟上手

**[打开游戏](https://arc-shift.black-kid-3047.chatgpt.site/)** → **第一次跃迁 / 行动演练** → 完成提示 → **开始行动**。

## 先学四个动作

| 操作 | 按键 | 使用时机 |
|---|---|---|
| 移动 | WASD / 方向键 | 离开敌人的攻击预警 |
| 瞄准并攻击 | 鼠标 + 左键 | 保持距离并持续输出 |
| 跃迁 | Space | 躲过危险，注意冷却 |
| 暂停 | Esc | 查看操作、调整设置或暂时离开 |

进阶：Q 脉冲、E 引力、B 炸弹、R 灵药。消耗品需要库存；技能受冷却或资源限制。设置里可改键。

## 一局怎么推进

主线中清理当前遭遇，选择一个奖励协议，再选择下一条路线。协议会改变攻击形态和元素组合；优先读卡片里的收益与代价。尽量保留灵药给受伤时使用。

想玩更短的固定流程，可从首页进入构筑远征、边境行动或中继争夺。各模式的目标以画面提示为准，训练和独立模式不会替换主线检查点。

## 存档与恢复

主线使用检查点保存，不保证恢复战斗中的每一帧。离开前看暂停页的保存说明，下次点「继续行动」。开始新行动会替换已有主线进度，请仔细看确认提示。存档只在当前设备、当前浏览器、当前站点中保留，不会自动同步到另一台电脑。

要换电脑：在「系统设置 → 存档备份」点击「下载存档备份」，保留 JSON 文件；在新电脑同一站点的主界面进入设置，选择备份、检查摘要，再点击「替换并恢复存档」。备份包含主线检查点、营地进度和声音/语言设置；独立模式记录和自定义按键需单独设置。恢复前建议先备份新电脑上的现有进度。

## 常见问题

- **没有声音**：先点击游戏，再到系统设置检查音乐/音效；检查浏览器标签页是否静音。
- **卡顿**：在系统设置降低视觉效果，关闭其他占用资源的标签页。
- **黑屏或加载失败**：使用页面重试；仍失败时更新 Chrome/Edge 后刷新。不要先清理站点数据，以免丢失存档。
- **手机不能操作**：目前需要电脑键盘和鼠标，没有触屏战斗控制。
- **手柄**：支持标准 Gamepad API 的战斗输入，但菜单仍建议键鼠；没有完成实体手柄兼容性认证。
